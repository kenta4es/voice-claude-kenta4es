# Voice Output — озвучка ответа

## Правило (одинаковое для любого чата — локального, облачного, обычного)

1. Сначала полностью составь финальный ответ.
2. **Первым действием** вызови инструмент озвучки claude-tts `speak` и передай этот ответ **ДОСЛОВНО и ЦЕЛИКОМ**: каждое предложение, готовые тексты (письмо, объявление, сообщение клиенту, цитата — в том числе в блоке-рамке) и **всё, что идёт после них**. Не пересказывай, не сокращай, не заканчивай голос словами «текст ниже» / «итог ниже».
3. Затем напиши в чат ровно тот же текст.

Имя инструмента: `mcp__claude-tts__speak` в локальных сессиях; в облачных сессиях, связанных с компьютером, он может называться с префиксом `remote-devices` (например `mcp__remote-devices__claude-tts__speak`). Используй тот, что есть. Если инструмента озвучки нет совсем — просто отвечай текстом.

**Промежуточные сообщения по ходу длинной работы** («Понял, проверяю журнал», «Нужно твоё участие: …», важные промежуточные итоги) — тоже через `speak`, сразу, дословно.

Где работает автоозвучка `tts-watch` (локальные чаты Cowork), она дочитывает с экрана только то, что ты не озвучил, — повторов не будет. Но полагаться на неё нельзя: в облачных и обычных чатах её нет.

## Что убирать из текста для `speak`

Markdown-символы (слова оставь), код, команды, конфиги, пути, URL, длинные ID, таблицы, служебные строки интерфейса, список «Источники». Блоки с **человеческим текстом** — читать.

## Очередь

Речь никогда не перебивается: каждый `speak` и ответы из других чатов встают в очередь; между сообщениями движок сам скажет «Следующее сообщение». `queue=true` — только если продолжаешь то же сообщение частями.

## Язык

Говори на языке пользователя. Иноязычный готовый текст для голоса переведи или замени фразой «дальше готовый текст на английском».

## Когда молчать

- Пользователь выключил озвучку в чате командой **`/voice`** (нечётное число вызовов = выключено). Обычные слова («тихо») ничего не выключают.
- `speak` вернул ошибку — пропусти в этом ответе, не извиняйся.

## Команды управления голосом

| Пользователь сказал | Tool |
|---|---|
| «переключи на Свету» / «Ирину» | `set_voice` |
| «быстрее» / «медленнее» | `set_rate` ±1 |
| «громче» / «тише» (про громкость) | `set_volume` ±10 |
| «покажи голоса» | `list_voices` |
| «стоп» / «замолчи» | `stop` |
| «пауза» / «продолжай» | `pause` / `resume` |

## Как пользователю управлять озвучкой (расскажи, если спросит)

- **`/voice`** — выключить / снова включить озвучку в этом чате.
- **Ctrl+Alt+A** — звук вкл/выкл везде. **Ctrl+Alt+плюс / минус** — громкость.
- **Ctrl+Alt+C** — стоп и очистка очереди. **Ctrl+Alt+X** — пауза. **Ctrl+Alt+R** — перезапуск, если пропал звук.
- **Ctrl+Alt+Z** — прочитать выделенный текст в любом окне.
