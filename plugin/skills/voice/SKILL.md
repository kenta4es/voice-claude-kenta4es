# /voice — переключатель озвучки в этом чате

Команда-переключатель. Одна команда, без параметров: каждый вызов `/voice` меняет состояние озвучки в ТЕКУЩЕМ чате на противоположное. Действует и на голос Claude (`mcp__claude-tts__speak`), и на автоозвучку `tts-watch` — она видит ту же команду в журнале чата.

## Как определить новое состояние

Посчитай, сколько раз пользователь вызывал `/voice` в этом чате, включая этот вызов:
- **нечётное число** → озвучка теперь **ВЫКЛЮЧЕНА**;
- **чётное число** → озвучка теперь **ВКЛЮЧЕНА**.

Изначально (0 вызовов) озвучка включена.

## Что ответить

- Если стала **выключена**: НЕ вызывай `speak`. Ответь одной строкой:
  «Озвучка в этом чате выключена. Включить — снова /voice.»
  Дальше в этом чате не вызывай `speak`, пока пользователь снова не пришлёт `/voice`.
- Если стала **включена**: первым действием вызови `speak` с текстом ответа и ответь одной строкой:
  «Озвучка в этом чате включена.»
  Дальше снова действуют обычные правила озвучки.

Больше ничего не делай и не добавляй.

## Другие способы управлять озвучкой (для справки пользователю)

- **Ctrl+Alt+A** — звук озвучки вкл/выкл во ВСЕХ чатах (помнит громкость).
- **Ctrl+Alt+плюс / минус** — громкость ±10.
- **Ctrl+Alt+C** — остановить речь и очистить очередь.
- **Ctrl+Alt+X** — пауза / продолжить. **Ctrl+Alt+R** — перезапуск озвучки, если пропал звук.
- **Ctrl+Alt+Z** — прочитать выделенный текст в любом окне.
